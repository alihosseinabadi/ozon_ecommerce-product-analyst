# Ozon E-commerce Analysis (Product Analyst)

Product analytics project for Ozon marketplace data: cleaning, category/product
trend analysis, a Streamlit dashboard, and business recommendations.

## Contents
- `ozon_ecommerce.ipynb` — Exploratory data analysis & cleaning notebook
- `dashboard.py` — Streamlit dashboard for interactive exploration
- `ozon_clean_data.csv` — Cleaned dataset
- `ozon_category_analysis.csv` — Category-level analysis
- `ozon_top_products.csv` — Top performing products
- `ozon_trending_products.csv` — Trending products
- `ozon_recommendations.txt` — Business recommendations

## Usage
```bash
pip install pandas streamlit
streamlit run dashboard.py
```
